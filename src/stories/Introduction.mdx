# Welcome to Your Storybook

This is your design system and component library for the **crypto-asset-tracker-app**.

## What's Included

- **🧱 Bricks Components**: Reusable UI components organized by functionality
- **📱 Responsive Design**: Components built with Tailwind CSS for mobile-first design
- **♿ Accessibility**: Components follow WCAG guidelines with proper ARIA labels
- **🧪 Testing**: Each component has comprehensive Jest tests
- **📖 Documentation**: Interactive documentation with controls and examples

## Component Organization

Components are organized in the `src/components/bricks/` directory:

- `StarRating/` - Star rating component with review counts
- `Button/` - Various button styles and states
- `Card/` - Card layouts and containers
- `Icon/` - Icon components using Lucide React
- `Text/` - Typography components
- And more...

## Getting Started

1. **Browse Components**: Explore the component library in the sidebar
2. **Interactive Controls**: Use the Controls panel to modify component props
3. **View Code**: Check the "Show code" option to see implementation details
4. **Responsive Testing**: Use the viewport toolbar to test different screen sizes

## Development

- **Add Components**: Follow the pattern in `src/components/bricks/`
- **Write Stories**: Create `.stories.tsx` files for each component
- **Add Tests**: Include `.test.tsx` files using Jest and React Testing Library
- **Follow Standards**: Adhere to the best practices defined in the project rules

## Available Scripts

```bash
# Start Storybook development server
yarn storybook

# Build Storybook for production
yarn build-storybook
```
